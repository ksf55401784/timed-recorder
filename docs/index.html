关于后台定时的限制

• 本 Web App：在应用保持打开/后台保活时可准点录音；锁屏或被杀后不会触发。
• Android 原生：用前台服务 + AlarmManager/WorkManager 可实现锁屏准点录音（需要我可另出 Android 工程）。
• iOS：系统不允许任意定时录音，仅能在 App 前台录音。
若你需要真正可靠的「锁屏也录」，告诉我目标平台，我给你做原生方案。
